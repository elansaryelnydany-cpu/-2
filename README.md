# مكتبة وورد الأنصاري — Windows
نسخة مستقلة تجريبية لويندوز x64. فك ZIP وشغّل ElansaryWordLibrary.exe. الحزمة غير موقعة رقميًا؛ لا تتجاوز تحذيرات الأمان دون التحقق من المصدر.

المتاح: إضافة ملفات DOCX أو مجلدات وفروعها، حفظ قائمة المسارات محليًا، تحديد ملفات البحث، بحث كلمات دون ترتيب داخل الفقرة وعبارات بين علامتي اقتباس، نتائج مجمعة حسب المجلد والملف، تلوين ونسخ كل نتيجة، عارض نصي للقراءة والانتقال إلى الفقرة المطابقة، طي وفرد النتائج وتقرير أخطاء.

القيود: لا يدعم DOC القديمة بعد. العارض نصي وليس عرض تنسيق Word الأصلي. يقرأ متن DOCX بما فيه نص الجداول دون تنسيقها، ولا يشمل الحواشي أو الرؤوس والتذييلات. لا توجد فهرسة محتوى دائمة أو سجل بحث أو نسخ جماعي بعد. حد النتائج 2000 وحد XML للمستند 32 MB. الملفات الأصلية لا تُعدّل. الفحص يتجاوز الروابط ونقاط إعادة التحليل. إزالة كل التحديد تعني البحث في المكتبة كلها. الاختبارات تتحقق من القراءة والبحث والفحص فقط؛ الواجهة والأداء يحتاجان اختبارًا فعليًا على ويندوز 11.

الحفظ المحلي لقائمة الملفات: LocalApplicationData/ElansaryWordLibrary/files.json. لا تُرفع المستندات إلى GitHub أو الإنترنت بواسطة التطبيق.
