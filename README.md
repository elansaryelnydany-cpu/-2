# مكتبة وورد الأنصاري - Windows

تطبيق ويندوز للبحث في ملفات DOCX وعرض النتائج.

## التشغيل

1. نزّل أحدث إصدار من صفحة Releases.
2. فك ضغط الملف.
3. شغّل `ElansaryWordLibrary.exe`.

## الميزات

- إضافة مجلد أو ملفات DOCX.
- بحث بكلمات متعددة أو عبارة بين علامتي تنصيص.
- شجرة نتائج ونسخ النتائج.
- عارض نصي ينتقل إلى الفقرة المطابقة.
